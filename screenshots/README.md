# Screenshot provenance

These are genuine captures from the nine independent **v1.1.1** local mock-service validation executions. They illustrate the preserved UI and report designs; they are not claimed as fresh v1.1.2 interactive GUI verification. No screenshots or metrics were generated for this release.

JMeter title bars were cropped by 32 pixels to avoid publishing machine-specific filesystem paths. Images were losslessly re-encoded as PNG; content pixels were not retouched, redrawn or composited. Original complete evidence remains local. Excel images are actual WPS Office captures; HTML images are actual offline browser captures.

The Manual image is an **unapplied analytical preview**, not proof of a Standard native ramp-down. Standard has no native gradual ramp-down. Excel/HTML examples use Ultimate, which supports the three displayed phases. Older Dashboard captures retain the old Requests/sec label; v1.1.2 uses Current throughput in samples/sec with completed-second windows.
