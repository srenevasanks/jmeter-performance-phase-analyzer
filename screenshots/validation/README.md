# Complete Thread Group validation screenshot collection

**252 original captures across nine independent v1.1.1 validation executions.** All nine groups retain Partial overall validation status. The existing 36-image curated gallery remains published; combined screenshot count is 288. Some curated images illustrate the same original moments, but the complete collection preserves each original file and group provenance. No new performance test or screenshot was generated.

Original filenames and content are preserved byte-for-byte. Defect and unavailable-state captures are evidence, not passing-result claims. Manual screenshots are unapplied previews. Native phase omissions and capture gaps are documented in each group index. Screenshots may include historical local-path title bars; those paths are not installation instructions or dependencies.
